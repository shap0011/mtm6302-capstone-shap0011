## Project Overview

This project was developed as part of a capstone course and evolved into a fully functional web application using **HTML, CSS, and JavaScript**.

The app connects to a public Pokémon API to dynamically fetch and display Pokémon data, providing an engaging and responsive user experience.

---

## Features

- Browse Pokémon in a dynamic gallery
- View detailed Pokémon information (image, name, stats)
- Load additional Pokémon (pagination / “next 20”)
- Select and track your chosen Pokémon
- Fully responsive design (desktop, tablet, mobile)
- Custom UI designed in Adobe XD

---

## Technologies Used

- HTML5
- CSS3 (Responsive Design, Media Queries)
- JavaScript (ES6+)
- REST API (PokéAPI)
- Adobe XD (UI/UX Design)

## How It Works

- The app fetches Pokémon data from an external API
- Pokémon are displayed in a grid layout
- Clicking a Pokémon shows detailed information
- Users can load additional Pokémon dynamically
- Selected Pokémon are stored in a separate list
